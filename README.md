# Assistente Conversacional - Albion Online

Um assistente conversacional desenvolvido para auxiliar jogadores de **Albion Online** com informações, dicas, economia e estratégias dentro do jogo.

O projeto utiliza inteligência artificial e processamento de linguagem natural para criar uma experiência interativa, permitindo que usuários façam perguntas em linguagem natural sobre o universo de Albion Online.


---

## Funcionalidades

- Chat conversacional sobre Albion Online
- Informações sobre economia e mercado
- Respostas inteligentes utilizando IA
- Estrutura preparada para futuras expansões
